# 📊 Education-platform course analysis

An Excel and Power BI coursework case study examining course revenue, pricing, subscribers and subject categories. Joana's original report is dated **25 March 2023** and describes **3,676 courses** in a historical dataset. “Educative” is the case-study company context, not a claim of commissioned client work.

## 🔎 Analysis workflow

Import and combine course records → clean subject labels and dates → examine missing values → build pivots → compare subjects, prices and subscribers → communicate descriptive findings.

The report groups courses into web development (1,203), business finance (1,191), musical instruments (680), and graphic design (602). Recommendations in the report are historical interpretations, not proven causal effects.

## 🛠️ Reproduce and inspect

Download the workbook and open its data/pivot sheets before reviewing the dashboards. Open the PBIX in Power BI Desktop and inspect Power Query data sources before refreshing. The original source CSVs are not separately included. The Word file preserves the original narrative and layout; the text edition makes it readable without downloading Office files.

Package contents, sheet names and PBIX page metadata were inspected. Excel recalculation, Power BI refresh and a rendered Word-layout comparison were not available in this environment.
